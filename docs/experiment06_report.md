# 实验六报告：Content Gap 与 Brand Voice

## 1. 本实验解决的营销问题
蓝牙降噪耳机项目已有消费者痛点和竞品分析，但还不能直接回答“下一步应该做什么内容”。本实验用用户重要度、竞品主题覆盖率和证据强度筛选内容机会，并用Brand Voice约束策略表达。

## 2. 数据与证据
输入为实验四、实验五的聚合成果。样本是399条教学模拟评论，覆盖Apple AirPods、Bose、华为 FreeBuds和索尼。用户证据保留实验四的review_id；竞品覆盖证据使用实验五的品牌-主题覆盖率记录。

## 3. 机会评分结果
|主题|用户重要度|竞品平均覆盖率|内容缺口|机会分数|判定|
|---|---:|---:|---:|---:|---|
|佩戴舒适|23.3%|16.04%|83.96%|95.19|高优先级内容机会|
|价格|11.3%|11.29%|88.71%|70.81|候选内容机会|
|音质|11.3%|12.05%|87.95%|70.58|候选内容机会|
|包装|9.3%|1.99%|98.01%|69.29|候选内容机会|
|连接稳定|8.0%|4.75%|95.26%|65.78|候选内容机会|

续航和降噪虽然存在内容缺口，但当前用户证据和重要度不足，被程序标记为伪机会，避免仅凭“竞品没覆盖”作出内容决策。

## 4. 评分公式
`机会分数 = 100 × (0.50 × 用户重要度归一化 + 0.30 × 内容缺口 + 0.20 × 证据强度)`。

程序计算负责评分、排序和证据表生成；Brand Voice Skill负责表达检查；Brief中的策略是基于证据的行动建议，不是新的统计事实。

## 5. 策略产出
已生成5条Brief：佩戴舒适、价格、音质、包装、连接稳定。每条包含目标人群、用户问题、内容方向、用户证据编号、竞品覆盖证据编号、品牌表达规则和预期指标。

## 6. 限制与合规
数据为教学模拟数据，不代表真实市场份额或真实销量。竞品覆盖率是评论主题提及的代理指标，不等于竞品全部内容资产。当前用户证据表对部分主题没有直接评论证据，因此这些主题不会进入前五条策略Brief。数据未包含个人敏感信息。
